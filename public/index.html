WALLET SETUP

Connect MetaMask

CricketVerse needs a wallet extension to sign blockchain transactions.

Install MetaMask
  1. Install MetaMask here, then create or unlock a wallet.
  2. Start the local Hardhat node and deploy the demo contracts if they are not already running.
  3. Open this site in Chrome with MetaMask. Click Connect Wallet and approve the local network switch.
  4. On the local demo, click Get 20 demo ETH, then claim 1,000 CRIC in each demo wallet.

Open localhost in Chrome with the extension. The built-in app browser cannot access Chrome extensions.
